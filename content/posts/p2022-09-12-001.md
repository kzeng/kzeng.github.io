### 

生成静态文件 `hexo g`
部署 `hexo d`
清除public 下所有静态文件(慎用) `hexo clean`
撰写文章 `hexo new "my article"`

### 

以token 方式, Github 最近因为安全问题取消了账号密码方式认证，而采取token 方式认证。

config.yml 写法如下:

deploy:
  type: git
  repo:
    github:
      url: <repository url>
      branch: [branch]
      token: ''
  message: [message]
  name: [git user]
  email: [git email]
